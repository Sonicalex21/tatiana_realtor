## ⚙️ Настройка профилей и заявок (`site-config.js`)

Все персональные ссылки и каналы получения заявок собраны в одном файле `site-config.js`:

```javascript
window.SITE_CONFIG = {
  specialist: {
    fullName: "Васильева Татьяна Геннадьевна",
    phoneDisplay: "8 965 680 98 98",
    phoneTel: "+79656809898"
  },
  socialLinks: {
    vk: "https://vk.com/tatiana_vas_realtor_monolit",
    instagram: "https://www.instagram.com/tatiana_vas_realtor/",
    max: "https://max.ru/89656809898"
  },
  leadSettings: {
    // Автоматическое сохранение всех заявок в браузерный реестр
    saveToLocalStorage: true,

    // Надежная доставка на Email риелтора через защищенный закрытый шлюз
    email: {
      enabled: true,
      recipientEmail: "tana3105@mail.ru"
    },

    // Внешний закрытый Webhook (для CRM или защищенного бэкенда)
    webhook: {
      enabled: false,
      endpointUrl: ""
    }
  }
};
```

### Реестр заявок (Lead Ledger):
- Заявки клиентов **никогда не потеряются**: каждая отправка моментально дублируется в защищенное локальное хранилище.
- Чтобы просмотреть сохраненные заявки или выгрузить их в JSON/Excel:
  - Нажмите сочетание клавиш **`Ctrl + Shift + L`** на сайте;
  - Либо кликните по служебной ссылке *«Реестр заявок»* в самом низу подвала.

## 🚀 Публикация на хостинге / домене

Сайт полностью автономен и не требует базы данных или сервера Node.js/PHP:
1. Зарегистрируйте домен (например, `васильева-недвижимость.рф` или `tatyana-vasileva.ru`).
2. Скопируйте все файлы из этой папки в корневую директорию хостинга (`public_html` / `www`).
3. Сайт сразу готов к работе, индексации поисковиками и приему заявок.
