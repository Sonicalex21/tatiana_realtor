## 📇 Цифровая визитка (2 формата)

В папке `business-card/dist/` подготовлены 4 готовых файла:

1. **Горизонтальная версия (1536 × 1024 px, соотношение 3:2):**
   - `business-card-horizontal-1536x1024.png` (высокая четкость без сжатия)
   - `business-card-horizontal-1536x1024.jpg` (оптимальный размер для отправки в чатах)
   - *Назначение:* отправка в мессенджерах на ПК, вложения в коммерческие предложения, электронную почту и презентации.

2. **Вертикальная версия (1080 × 1350 px, соотношение 4:5):**
   - `business-card-vertical-1080x1350.png`
   - `business-card-vertical-1080x1350.jpg`
   - *Назначение:* экраны смартфонов, посты во ВКонтакте, Stories/Reels, заставка на телефон.

> **Соблюдение регламента:**  
> - На изображениях визиток размещены только контакты **Телефон**, **Макс** и **VK**.  
> - *Instagram и Telegram на изображении визитки отсутствуют.*  
> - Руки на портрете полностью скрыты, черты лица и внешность Татьяны сохранены в оригинальном виде.

## ⚙️ Настройка профилей и заявок (`site-config.js`)

Все персональные ссылки и каналы получения заявок собраны в одном файле `site-config.js`:

```javascript
window.SITE_CONFIG = {
  specialist: {
    fullName: "Васильева Татьяна",
    phoneDisplay: "8 965 680 98 98",
    phoneTel: "+79656809898"
  },
  socialLinks: {
    vk: "https://vk.com/tatiana_vas_realtor_monolit",
    instagram: "https://www.instagram.com/tatiana_vas_realtor/",
    max: "https://max.ru/89656809898"
  },
  leadSettings: {
    // Автоматическое сохранение всех заявок в браузерный реестр
    saveToLocalStorage: true,

    // Мгновенные уведомления в Telegram Татьяне
    telegram: {
      enabled: true,
      botUsername: "@LeadsFromTatiana_Bot",
      botToken: "9052645040:AAH50D1kti3jFsInRkaQSChoXJsgLvmiPYQ",
      chatId: "ЦИФРОВОЙ_CHAT_ID"
    }
  }
};
```

### Реестр заявок (Lead Ledger):
- Заявки клиентов **никогда не потеряются**: каждая отправка моментально дублируется в защищенное локальное хранилище.
- Чтобы просмотреть сохраненные заявки или выгрузить их в JSON/Excel:
  - Нажмите сочетание клавиш **`Ctrl + Shift + L`** на сайте;
  - Либо кликните по служебной ссылке *«Реестр заявок»* в самом низу подвала.

## 🚀 Публикация на хостинге / домене

Сайт полностью автономен и не требует базы данных или сервера Node.js/PHP:
1. Зарегистрируйте домен (например, `васильева-недвижимость.рф` или `tatyana-vasileva.ru`).
2. Скопируйте все файлы из этой папки в корневую директорию хостинга (`public_html` / `www`).
3. Сайт сразу готов к работе, индексации поисковиками и приему заявок.
